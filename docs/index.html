A fast, local-first home for games from Steam, Heroic (Epic, GOG, and Amazon), Lutris, Faugus, GOG, Battle.net, Microsoft Store and PC Game Pass, RetroArch, and ten standalone console emulators. Built for Linux and styled to match Omarchy.

Install on Omarchy

Omakade is in the Omarchy Package Repository (OPR). Install it with:

sudo pacman -S omarchy/omakade

It then updates with omarchy update. OPR may carry an older release.

On plain Arch, or for the newest release on Omarchy, add the signed package repository once and install from it. It provides x86_64 and ARM64 packages:

curl -fsSL https://pkgs.btso.dev/install.sh | bash
sudo pacman -S btsouth/omakade

Updates then arrive with your normal system update (sudo pacman -Syu on plain Arch). On Omarchy, OPR's copy takes priority during system updates; to take a newer version from the signed repository early, run omarchy update and then sudo pacman -S btsouth/omakade.
